    Building

    Prerequisites

    apt install git zip cmake build-essential xxd python3-pip python3-setuptools python3-wheel python3-dev
# For IIO support (also build libiio v0.26 from source):
apt install libavahi-common-dev libavahi-client-dev libaio-dev libusb-1.0-0-dev libxml2-dev

    yum groupinstall -y "Development Tools"
yum install -y git zip cmake make gcc gcc-c++ vim-common python3-pip python3-setuptools python3-wheel python3-devel

    • Visual Studio 2019 or 2022 Build Tools (C/C++ workload)

    • CMake (bundled with VS or standalone)

    • 7z.exe on PATH

    • Inno Setup 6 (for installer generation)

    • Optionally: libiio v0.26 release ZIP for IIO support

    Local Build (Linux)

    # Choose an API version
API=v68.16.2

cd $API
bash apply_updates.sh

cd navassa-profile-gen
mkdir build && cd build
cmake -DENABLE_TESTS=ON -DENABLE_IIO=OFF -DENABLE_TOOLS=ON \
      -DGENERATE_REF_PROFILE_HEADER=ON -DADRV9002_API_VERSION=68.16.2 ..
make -j$(nproc)
ctest -V

    Local Build (Windows)

    $API = "v68.16.2"
cd $API

# Apply patches (use git bash or adapt for PowerShell)
bash apply_updates.sh

cd navassa-profile-gen
mkdir build; cd build

# Configure (quote the version to avoid dot-parsing issues)
cmake -S .. -B . -DENABLE_TESTS=ON -DENABLE_IIO=OFF -DENABLE_TOOLS=ON `
      "-DADRV9002_API_VERSION=68.16.2"

# Build
cmake --build . --config Release

# Test
ctest -V -C Release

    Note

    On Windows, the -DADRV9002_API_VERSION=68.16.2 argument must be quoted to prevent CMake from interpreting the dots as extra path components.

    CMake Options

    Option

    Default

    Description

    ENABLE_IIO

    OFF

    Enable libiio integration (requires libiio installed)

    ENABLE_TESTS

    OFF

    Build unit tests

    ENABLE_DOC

    OFF

    Build Sphinx documentation

    ENABLE_TOOLS

    OFF

    Build CLI tools (adrv9002-iio-cli)

    ADRV9002_API_VERSION

    68.8.1

    API version string

    GENERATE_REF_PROFILE_HEADER

    OFF

    Generate profile.h from reference JSON via xxd

    ENABLE_STDFS

    OFF

    Use std::filesystem (needed on Fedora)

    HARDWARE_TEST

    OFF

    Enable hardware-in-the-loop tests (requires real board)

    Build Script Flow

    CI uses shared scripts from build_scripts/ that are copied into the version directory:

    run_preinstall.sh  →  Install OS packages, optionally build libiio from source
         ↓
run_build.sh       →  Call apply_updates.sh, then cmake/make/ctest/cpack
         ↓
apply_updates.sh   →  Apply patch, copy deps, clone pinned sub-repos

    Building with IIO Support

    IIO support requires libiio v0.26. On Linux, build from source:

    git clone -b v0.26 --single-branch --depth 1 https://github.com/analogdevicesinc/libiio.git
cd libiio
cmake . -DHAVE_DNS_SD=OFF
make && sudo make install

    Then configure with -DENABLE_IIO=ON.

    On Windows, download the libiio v0.26 release ZIP and pass:

    -DLIBIIO_LIBRARIES:FILEPATH="C:\deps\Windows-VS-2019-x64\libiio.lib"
-DLIBIIO_INCLUDEDIR:PATH="C:\deps\include"
