**libadrv9002-iio** is provided in binary form for multiple architectures and operating systems.
All packages are available after accepting the license terms below.

## Choosing a Package

Each release provides two independent choices per platform:

- **Installer/package vs. library ZIP** — the `-setup.exe` / `.deb` installs the library
  system-wide (DLLs or `.so`, headers, and the `adrv9002-iio-cli` tool on your PATH). The
  companion `.zip` contains the same files unpacked, for embedding into another build or
  installing to a custom location without a system-wide install.
- **libiio support** — the packages listed below are all built **without** libiio (the
  **libiio** column reads `NA`), so they only generate profile JSON/stream binaries to
  disk. Builds linked against
  [libiio v0.25](https://github.com/analogdevicesinc/libiio/releases/tag/v0.25), which add
  the ability to push a generated profile straight to hardware over network/USB via
  `adrv9002_generate_load_profile_iio()`, are currently produced only by CI for
  development use — see [Installation → IIO Support](installation) for naming and details.
