    Command Line Tool

    The adrv9002-iio-cli command-line tool lets you generate ADRV9002 profiles and stream images directly from a JSON configuration file, without writing any code. This is useful for scripting, CI/CD pipelines, and quick testing of configuration changes.

    Installation

    The CLI is included in:

    • Linux .deb packages

    • Windows installer

    • Source builds with -DENABLE_TOOLS=ON

    It is not included in Python wheel packages.

    Usage

    adrv9002-iio-cli [OPTIONS]

Options:
  -c, --config <file>     Input JSON configuration file (required)
  -p, --profile <file>    Output profile JSON file
  -s, --stream <file>     Output stream binary file
  -h, --help              Show help

    Example

    # Generate profile and stream from config
adrv9002-iio-cli -c config.json -p profile.json -s stream.bin
