# navassa-pg-library

Developer and user documentation for the ADRV9002 profile generation library packaging repository.

This repository wraps the `navassa-profile-gen` library source (via git submodules) with version-specific patches, dependencies, and CI/CD infrastructure to produce multi-platform packages (DEB, RPM, ZIP, Windows installer, Python wheels) for **libadrv9002-iio**.
