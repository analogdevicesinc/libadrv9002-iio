# Repository Architecture

## Purpose

This repository is a **packaging wrapper** around the `navassa-profile-gen` C++ library. It does not contain the library source directly. Instead, it:

1. Pins a specific commit of `navassa-profile-gen` as a git submodule per API version
2. Applies version-specific patches to adapt the library for packaging
3. Vendors dependencies (Common API headers) that are not publicly available
4. Provides build scripts for multi-platform CI/CD
5. Produces installable packages (DEB, RPM, ZIP, Windows installer, Python wheels)

## Key Constraints

### Submodules Are Read-Only

The `navassa-profile-gen` submodule and its nested submodules (`libadrv9002`, `stream-gen-src`, `profile-types-c`) **cannot be modified directly**. All changes must be expressed as patch files:

- `profile_gen.patch` — applied to navassa-profile-gen root
- `stream_gen.patch` — (v68.16.2 only) applied to stream-gen-src

### Build Scripts Are Shared

Scripts in `build_scripts/` are **version-agnostic**. CI copies them into the active version directory before execution (`cp build_scripts/* $API/`). Do not add version-specific logic to these scripts.
