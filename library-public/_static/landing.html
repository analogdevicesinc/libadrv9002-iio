libadrv9002-iio

Profile generation library for the ADRV9002/3/4 family of RF transceivers

Latest: v0.3.1

Releases

Each release supports one or more ADRV9002 Device Driver API versions. Select your API version to view the corresponding documentation.

v0.3.1 Latest

Upgrades libiio to v0.26, adds bare-metal (Cortex-M4F) package support, completes and publishes the C/C++ API reference, and hardens shipped binaries (stripped symbols, no leaked build paths, header included in every zip).
