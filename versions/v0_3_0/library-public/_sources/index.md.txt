# ADRV9002 Transceiver Profile Generator

**libadrv9002-iio** is a software library for generating configuration profiles for the ADRV9002/3/4 family of RF transceivers. It provides programmatic C and Python interfaces equivalent to the Transceiver Evaluation Software (TES), compiled for multiple CPU architectures and operating systems.

The library takes a set of radio and clock parameters as input and produces two outputs:
- A **profile JSON** — the full device initialization structure
- A **stream image** — binary firmware loaded onto the transceiver's stream processor

These outputs can then be written to hardware via the IIO kernel driver, or saved to files for later use.

```{note}
This documentation involves three distinct, independently-versioned things — don't
confuse them:
- **libadrv9002-iio release version** (e.g. **{{release}}**) — this library's own version,
  used to organize this documentation site.
- **ADRV9002 Device Driver API version** (e.g. **{{api_version}}**) — the transceiver API
  version a given library release supports.
- **TES version** — Transceiver Evaluation Software is a separate ADI product with its own,
  unrelated version numbers.
```

## Limitations

Specific versions of the transceiver API are supported by this library. This is currently **{{api_version}}** for this version. If you need a previous version, see [previous releases](https://github.com/analogdevicesinc/libadrv9002-iio/releases).

Features not yet available:
- DPD
- Tracking calibrations
- Power monitoring modes
- GPIO controls
- AUX ADC/DAC controls
- FPGA-specific features (Fast Frequency Hopping, TDD FPGA IP)

If you require these features, please use TES.
